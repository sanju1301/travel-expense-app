# Travel Expense - Step 1

A Flutter UI shell for Android and Web. This step contains sample data only; Firebase, login, camera, and cloud persistence come in later builds.

## Build the APK using GitHub only

1. Create an empty GitHub repository.
2. Upload all files from this package, including the `.github` folder.
3. Commit to the `main` branch.
4. Open **Actions** and select **Build Android APK**.
5. Run the workflow, or let the push trigger it automatically.
6. Open the successful run and download `travel-expense-step1-apk` under **Artifacts**.
7. Extract the ZIP and install `app-debug.apk` on your Android phone.

Android may ask you to allow installation from your browser or file manager. Only install the APK produced by your own repository.

## Step 1 features

- Responsive Material 3 interface with Cupertino-style icons
- Home dashboard with sample expenses
- Expense list and filter chips
- Add-expense form preview
- Profile/settings preview
- Light and dark themes
- Widget test and static analysis in GitHub Actions
